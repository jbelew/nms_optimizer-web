# Estatísticas do NMS Optimizer: Layouts de Tecnologia Mais Populares

## Estatísticas de Uso e Layouts Populares

Esta página agrega dados dos usuários do NMS Optimizer para revelar as tecnologias mais frequentemente supercarregadas em diferentes plataformas. Esteja você planejando sua próxima build ou buscando inspiração, estas estatísticas mostram preferências e padrões reais da comunidade.

## Entendendo os Dados

Os gráficos abaixo exibem estatísticas agregadas de usuários dos últimos **28 dias**, mostrando quais tecnologias os jogadores mais costumam otimizar para **espaços supercarregados**. Os dados representam milhares de sessões de otimização em três tipos principais de plataforma:

- **Tecnologias de Nave** - Incluindo variantes de naves Padrão, Sentinela e Solares
- **Tecnologias de Multiferramenta** - Abrangendo multiferramentas Padrão, Sentinela, de Atlante e Bastões
- **Tecnologias de Corveta** - As naves corsárias especializadas introduzidas na atualização **Voyagers**

## O que Estes Gráficos Significam

Cada gráfico mostra a popularidade relativa das diferentes tecnologias quando os usuários escolhem supercarregá-las. Uma fatia maior significa que aquela tecnologia foi selecionada para supercarregamento com mais frequência pela comunidade. Isso reflete:

1. **Eficiência no Meta** - Tecnologias que oferecem os maiores ganhos de desempenho tendem a se concentrar no topo
2. **Preferências dos Jogadores** - Jogadores focados em combate priorizam tecnologias diferentes dos focados em exploração
3. **Oportunidades de Sinergia** - Algumas tecnologias combinam especialmente bem com espaços supercarregados, tornando-se escolhas naturais

### Lendo os Gráficos

- Tecnologias que representam menos de **2% do total de seleções** são agrupadas na categoria "Outras" para manter os gráficos legíveis
- As porcentagens aparecem em cada fatia quando representam pelo menos 6% do total
- As cores das tecnologias correspondem às cores usadas em todo o otimizador para facilitar a consulta

## Por que Isso Importa

Entender os padrões da comunidade pode ajudar a orientar suas próprias decisões de build:

- **Validação** - Se uma tecnologia que você está considerando é popular, provavelmente há um bom motivo
- **Descoberta** - Encontre tecnologias que você talvez não tivesse considerado ao ver o que outros jogadores priorizam
- **Mudanças no Meta** - Acompanhe como os dados mudam conforme o jogo evolui e novos conteúdos são lançados
- **Variedade de Builds** - Use estes dados como ponto de partida e personalize conforme seu estilo de jogo e suas necessidades específicas

## Primeiros Passos

Depois de conferir as escolhas populares aqui, acesse o [otimizador](/pt/) para criar sua própria build otimizada. Você pode:

1. Selecionar sua plataforma (Nave, Multiferramenta, Corveta, Exotraje ou Exoveículo)
2. Configurar seus **espaços supercarregados** e **espaços ativos**
3. Executar o solucionador para encontrar seu layout perfeito

Para instruções detalhadas sobre como usar o otimizador, visite a [página de instruções](/pt/instructions/).

## Coleta de Dados

Estes dados são coletados anonimamente a partir das solicitações de otimização e não incluem nenhuma informação de identificação pessoal. Eles ajudam a comunidade do NMS Optimizer a entender quais tecnologias entregam mais valor e orientam melhorias futuras nos algoritmos do solucionador.
