# Agent Markdown Content Negotiation on Cloudflare Free Tier

## Context

AI agents and machine readers requesting canonical pages with `Accept: text/markdown` previously received the full HTML document (`text/html; charset=utf-8`), forcing them to parse the HTML shell and **Static SEO Fallback** markup rather than clean Markdown. Cloudflare's native zone-level "Markdown for Agents" (`content_converter`) is restricted to Pro, Business, and Enterprise plans and is unavailable on our Cloudflare Free-tier zone.

Implementing `Accept: text/markdown` content negotiation directly on Cloudflare Pages + Cloudflare Free-tier Zone caching faces two hard architectural constraints:

1. **Static CDN Bypass & Pages Function Quotas**: [`public/_routes.json`](../../public/_routes.json) (enforced by [`scripts/verify-routes-consistency.mjs`](../../scripts/verify-routes-consistency.mjs) and [`scripts/verify-deployment.mjs`](../../scripts/verify-deployment.mjs)) explicitly excludes all 42 pre-rendered SSG HTML routes so browser page loads hit Cloudflare's static asset CDN (`cf-cache-status: HIT`) without invoking [`functions/[[path]].js`](../../functions/[[path]].js) or burning the 100,000 requests/day Free-tier Workers/Pages Function quota.
2. **Edge Cache Poisoning (`Vary: Accept` Ignored)**: Our Cloudflare Zone Cache Rules cache subpage entry points (`/about/*`, `/es/*`, etc.) at the edge (`edge_ttl: 300`, `override_origin`), and Cloudflare Free-tier CDN cache keys do not vary by general `Accept` headers. Serving `text/markdown` and `text/html` from the same cache-key URI path would allow an agent request on a cold edge PoP to cache `text/markdown` under `/about/` and serve raw Markdown to human browsers.

Meanwhile, [`scripts/generate-ssg.mjs`](../../scripts/generate-ssg.mjs) already compiles pages directly from first-party localized Markdown fragments (`public/assets/locales/{lang}/*.md`), [`getPageMetadata`](../../shared/page-metadata.js), and localized navigation links—making runtime HTML-to-Markdown scraping both wasteful and lossy.

## Decision

We implement **Agent Markdown Document** content negotiation for Cloudflare using build-time source-first Markdown synthesis paired with a Cloudflare Free-tier URL Rewrite Rule (`http_request_transform`) and a dedicated `/__md/*` Pages Function handler:

1. **Build-Time Source-First Synthesis (`dist/<route>/index.md`)**: [`scripts/generate-ssg.mjs`](../../scripts/generate-ssg.mjs) generates a standalone **Agent Markdown Document** (`index.md`) alongside every SSG `index.html` across all 42 public localized routes (`/` and `about`, `instructions`, `changelog`, `translation`, `userstats`, `privacy` across `en`, `es`, `fr`, `de`, `pt`, `it`). Each document consists of:
    - YAML frontmatter (`title`, `description`, `url`, `lang`, `image` from [`getPageMetadata`](../../shared/page-metadata.js)),
    - Sanitized body Markdown (top `#` heading normalized to `pageMetadata.heading`, custom `<radix-icon>` tags stripped via [`stripRadixIconTags`](../../scripts/markdown-processor.mjs), `[youtube:<id>]` shortcodes converted to standard Markdown links, and root-relative URLs expanded to `https://nms-optimizer.app/...`), and
    - A localized `## Navigation` section mirroring [`generateNavigationLinks`](../../scripts/generate-ssg.mjs), omitting the duplicated Schema.org JSON-LD blocks to minimize token overhead.
2. **Pre-Cache Zone URL Rewrite (`http_request_transform` → `/__md/*`)**: All 42 SSG HTML routes remain excluded in [`public/_routes.json`](../../public/_routes.json), and `"/*.md"` is also excluded so static `.md` assets bypass the Pages Function. A Cloudflare Zone URL Rewrite Rule (`http_request_transform`, which executes before Cache Rules and Cache Key calculation) matches incoming apex requests (`http.host eq "nms-optimizer.app"`) where `any(lower(http.request.headers["accept"][*])[*] contains "text/markdown")` (excluding `/__md`, `/__md/*`, `/build/*`, `/assets/*`, `/.well-known/*`, and static file extensions) and rewrites the path to `concat("/__md", http.request.uri.path)`.
3. **RFC 9110 Negotiation & Canonical Redirects in `functions/[[path]].js`**: When [`functions/[[path]].js`](../../functions/[[path]].js) receives a `/__md/*` request, it unwraps `/__md` to recover the public pathname, executes canonical `301` redirects (`www.`, trailing-slash enforcement, `?lng=`, `/en/` removal) against the public URL without leaking `/__md`, and evaluates RFC 9110 `Accept` quality weights (`q=`):
    - When `q(text/markdown) > 0` and `q(text/markdown) >= q(text/html)`, it fetches the pre-rendered `/.../index.md` asset via `env.ASSETS.fetch()` (including on `/` with **Shared Grid** `?platform=&grid=` query parameters) and returns `200 OK` with `Content-Type: text/markdown; charset=utf-8`, `Vary: Accept`, `x-markdown-tokens` (`Math.ceil(utf8Bytes / 4)`), `Content-Signal: ai-train=yes, search=yes, ai-input=yes`, and `Cache-Control: no-cache, must-revalidate, max-age=0` (paired with a 300s Cloudflare Zone edge TTL on pure Markdown `/__md/*` requests, while the trailing `cache: false` Cache Rule—placed last under Cloudflare's last-match-wins `http_request_cache_settings` evaluator—bypasses edge caching on direct non-Markdown `/__md/*` visits and weighted/mixed `Accept` headers so `301` redirects and `q=` HTML fallbacks never collide under the URI-only `/__md/*` cache key).
    - If `q(text/html) > q(text/markdown)` or a client requests `/__md/*` directly without `Accept: text/markdown`, it falls back or `301`-redirects to the canonical HTML route.
    - Client-only disallowed **Routed Dialog** paths (`/performance/*`) fall through to the existing `noindex,follow` HTML SPA fallback, and unknown paths preserve `404` responses.
4. **Agent Discoverability**: [`public/llms.txt`](../../public/llms.txt) links directly to canonical `/.../index.md` **Agent Markdown Documents** and documents `Accept: text/markdown` support, while SSG HTML `<head>` blocks emit `<link rel="alternate" type="text/markdown" href="..." />`.

## Considered Options

- **Cloudflare Native Markdown for Agents (`content_converter`)**: Enable Cloudflare's built-in edge HTML-to-Markdown converter. _Rejected_: Unavailable on Cloudflare Free tier, and scrapes rendered HTML rather than serving our clean first-party Markdown sources.
- **Un-exclude SSG Routes in `public/_routes.json` and Negotiate Directly on Canonical Paths**: Remove SSG route exclusions so `functions/[[path]].js` inspects `Accept` on every request. _Rejected_: Forces all human HTML page views through Pages Functions (`DYNAMIC` cache status, Free-tier invocation quota burn) and risks poisoning the 300s Cloudflare edge cache for human browsers because Free-tier CDN cache keys ignore `Vary: Accept`.
- **Pure Static URL Rewrite (`<path>` → `<path>index.md`) Without Pages Function**: Rewrite `Accept: text/markdown` directly to static `index.md` files. _Rejected_: Free-tier Transform Rules lack regex support, preventing RFC 9110 `q`-weight comparison, breaking trailing-slash `301` redirects on unslashed paths (`/about`), returning `404` instead of SPA fallback on `/performance/`, and consuming 42 of Cloudflare Pages' 100 `_headers` rule limit for per-page `x-markdown-tokens`.
- **Zone URL Rewrite to `/__md/*` Pages Function + Pre-rendered `dist/<route>/index.md` (Selected)**: Keeps 100% of browser HTML traffic on the static CDN, isolates HTML and Markdown cache keys before Cache Rules execute, and supports full RFC 9110 negotiation, canonical redirects, and zero-dependency `x-markdown-tokens` headers.

## Consequences

- Browser HTML traffic retains static CDN `HIT` status and zero Pages Function overhead; do **not** remove SSG paths from [`public/_routes.json`](../../public/_routes.json) to "simplify" content negotiation.
- Deploying to a new Cloudflare Zone requires applying the `http_request_transform` URL Rewrite Rule and `/__md/*` Cache Rule (provisioned via [`scripts/provision-cloudflare-zone.mjs`](../../scripts/provision-cloudflare-zone.mjs) and verified by [`scripts/verify-deployment.mjs`](../../scripts/verify-deployment.mjs)); `.pages.dev` preview subdomains do not run custom Zone Transform Rules and can be preview-tested via `/.../index.md` or `/__md/...`.
